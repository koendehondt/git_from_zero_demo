# Git from Zero

Every change you make, saved as a point on a line and lines you can split off and bring back together.


## Cheat sheet

git clone <url>
git status
git add <file>
git commit -m "…"
git log --oneline
git diff
git restore <file>
git pull
git push
git branch
git switch -c <name>
git switch <name>
git merge <name>
git merge --abort
